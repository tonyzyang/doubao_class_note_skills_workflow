# 阶段四：撰写「全讲复习」内容

在 `content.json` 的 `review` 中产出，顺序固定为：思维导图 → 复习路径 → 核心结论 → 自测 → 时间脉络 → 核心模块 → 数字速记 → 易混点 → 话术 → 迁移清单。

## 硬性边界

- **唯一允许画的是思维导图（ECharts tree）**；不画柱图、折线、饼图等课程图表，也不画数据表。其余全部用文字、列表、卡片表达。
- 全部内容来自逐字稿，不编造；可合并同类、去口语重复、改写成书面短句，但不删除知识颗粒。
- 各类条数没有上限，由实际内容决定：模块可能 5 个也可能 20 个，结论可能 8 也可能 30 条，照实写。模板里的 1–2 个示例只是结构，需复制扩到实际条数。

## 各部分怎么写

- **map（思维导图）**：根节点=本讲主题；一级分支=几大模块（≤8 字，10 个左右）；叶子=细知识点。叶子超过 ~15 个时必须 `initialTreeDepth:1`（构建器已内置，勿改），默认只展一级、点击展开，否则文字与连线重叠。
- **paths（复习路径，固定 4 卡）**：5 分钟（考前急救）/20 分钟（课后巩固）/45 分钟（系统复习）/迁移（框架应用）；卡内条目按实际写全。
- **conclusions（核心结论）**：每条一个可独立成立的判断；这是复习骨架，先写它。
- **quiz（自测，details）**：先自己开口作答再展开。现场问答放在最前（每题一条），其余是主动回忆题；answer 列要点。
- **timeline（时间脉络）**：按时间串关键节点（时间 + 一句话）。
- **modules（核心模块）**：每个知识簇一条，模块名 + 一句话本质。
- **numbers（数字速记）**：关键数字卡，值 + 含义/年份/口径；约数保留“约”。
- **confuse（易混点）**：易混概念对比、常见错误。
- **talks（话术）**：每段 30–60 秒可直接复述的口语化表达，覆盖高频考点。
- **transfer（迁移清单）**：把本讲框架迁移到新场景的具体动作。

## 去来源

HTML 里不写主讲人/单位/日期/“妙记转写/老师说”等旁观者与来源措辞、不写资料来源、不写 footer。统计数字按最终实际计数（构建器自动统计幻灯片/结论/自测/模块数）。
